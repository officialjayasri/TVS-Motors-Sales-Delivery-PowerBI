# TVS Motors Sales & Delivery Performance Analytics Dashboard

## Project Overview

Developed an interactive **Power BI dashboard** to analyze TVS Motors sales and delivery performance using **500,000+ rows of business data**. The project involved data cleaning, transformation, validation, modeling, and analysis to create KPI-driven reports for monitoring business performance and supporting data-driven decision-making.

## Business Objective

The objective of this project was to provide a centralized view of sales and delivery performance and enable users to:

* Monitor sales performance
* Track delivery performance
* Analyze dealer performance
* Identify sales and delivery trends
* Monitor key business KPIs
* Generate actionable business insights

## Data Preparation

* Worked with **500,000+ rows of TVS sales and delivery data**.
* Cleaned and validated the dataset using **Microsoft Excel and Power Query**.
* Handled missing values, duplicate records, inconsistent values, and data formatting issues.
* Transformed and prepared the data for reporting and analysis.
* Ensured data accuracy and consistency before dashboard development.

## Data Modeling & DAX

* Designed a structured data model to support sales and delivery analysis.
* Created **DAX measures** to calculate business KPIs and performance metrics.
* Used calculated measures to support dynamic analysis across different business dimensions.
* Applied appropriate relationships and data modeling techniques for efficient reporting.

## Dashboard Features

The interactive Power BI dashboard provides analysis of:

* Sales Performance
* Delivery Performance
* Dealer Performance
* Customer Insights
* Sales Trends
* Delivery Trends
* Key Performance Indicators

Interactive filters and visualizations enable users to analyze performance across different categories and business dimensions.

## Key KPIs

* Total Sales
* Total Deliveries
* Sales Growth
* Delivery Performance
* Dealer Performance
* Customer Metrics
* Monthly Sales Trends

## Tools & Technologies

* **Microsoft Power BI**
* **Power Query**
* **DAX**
* **Microsoft Excel**
* **Data Modeling**
* **Data Visualization**

## Project Workflow

**Data Collection → Data Cleaning → Data Validation → Data Transformation → Data Modeling → DAX Analysis → Dashboard Development → Business Insights**

## Outcome

The dashboard centralized sales and delivery performance reporting and reduced manual reporting effort by **40%**, enabling faster access to business KPIs and supporting data-driven decision-making.
